# 文章评估框架（运营视角）

写完初稿后，用此框架做自我评估，再迭代修改。

## 1. 情绪曲线

逐段标注读者可能产生的情绪，画出一条曲线。如果中间任何一段"平"了（没有情绪变化），读者会划走。

情绪锚点：共鸣（勾起回忆）→ 痛点（戳中问题）→ 冲击（数据/事实震撼）→ 实用（觉得有用）→ 紧迫（感到需要行动）→ 释然（看到希望）→ 行动（想做点什么）→ 金句（想转发）

## 2. 钩子密度

每段检查：读者凭什么继续读下去？钩子类型：

| 类型 | 示例 | 位置建议 |
|------|------|----------|
| 场景钩 | "烧烤摊上队友问我一句话" | 开头 |
| 数据钩 | "4-6个小时""差了30%" | 前1/3，越早越好 |
| 反常识钩 | "纠结越久成绩越差" | 中段 |
| 警示钩 | "AI错的跟对的一模一样" | 中后段 |
| 金句钩 | "这个题，到底在问什么" | 结尾 |

## 3. 目的达成度

| 目的 | 判断标准 |
|------|----------|
| 建立信任 | 有真实细节吗？（时间、地点、数字、对话） |
| 传递方法 | 具体可操作吗？（不是"要准备"而是"存好这三类代码"） |
| 制造紧迫 | 有数据支撑吗？（不是"很重要"而是"差了30%"） |
| 促成转发 | 结尾金句值得截图吗？ |

## 4. 完整性检查

- 全篇风格是否统一？（别前面讲故事后面变教程）
- 关键数据是否被埋没？（如果最重要的数字在第3段之后，往前移）
- 段落节奏是否割裂？（长叙事→突然列表→恢复叙事，需要加过渡句）
- 标题和结尾是否呼应？
