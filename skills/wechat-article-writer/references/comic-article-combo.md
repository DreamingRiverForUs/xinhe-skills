# 漫画配图 + 公众号文章组合模式

当文章叙事性强、有具体场景时，用极简手绘漫画代替传统流程图/信息图作为正文配图。

## 适用场景

- 文章开头有具体故事场景（对话、画面感强的描述）
- 文章中有"亲眼见证"类的事件（学弟算错、凌晨调格式）
- 想增加文章的口语感和人格化程度

## 工作流

1. 写完文章后，扫描文中**可漫画化的场景**，挑选 3-4 个最生动的
2. 用 baoyu-comic skill，minimalist 极简手绘风格，生成竖版单格漫画
3. 漫画 prompt 要点：
   - 场景具体（灯光、时间、人物动作）
   - 有中文对话气泡
   - 暖色奶油纸底
   - 火柴人/极简线条
4. 将漫画 PNG 复制到 Obsidian vault 的 `assets/配图/漫画/` 目录
5. 在文章对应位置嵌入 `![[assets/配图/漫画/漫画-NN-名称.png]]`
6. 同步 vault 的 git

## 效果评估

漫画配图比信息图/流程图的优势：
- 增加文章"人味"，降低 AI 写作痕迹
- 读者对场景产生共鸣（"我也经历过"）
- 视觉节奏：文字→漫画→文字的交替让阅读不累

## 已知陷阱

- 漫画数量 3-4 张为佳，过多会打断阅读节奏
- 不要用 ohmsha 日式漫画风格（本用户偏好极简手绘）
- 每张漫画竖版 1024x1536，用 zenmux gemini-3-pro-image-preview
