# User Style Preferences

This user (心河Paper founder) has tested the infographic skill and expressed clear preferences:

## Preferred style (use by default)
- **craft-handmade** (Hand-drawn variant) — warm cream paper (#FFF8F0), simple hand-drawn cartoon elements, organic imperfect lines, no photorealistic elements
- Also acceptable: **storybook-watercolor**, **chalkboard**

## Avoid
- **hand-drawn-edu** — user found this "好丑" (ugly); the macaron pastel color blocks look too digital
- Anything that looks like a "corporate template" or has flat vector icons
- Dark backgrounds with white text — unreadable

## Layout preferences
- **linear-progression** for process/roadmap content (most common use case)
- **bento-grid** for multi-topic overviews
- portrait 9:16 aspect ratio for mobile reading

- Generate via ZenMux Gemini protocol (google/gemini-3-pro-image-preview)
